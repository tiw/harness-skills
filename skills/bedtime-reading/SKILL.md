# 睡前读物

## 工作流程

1. **找素材**：在工作区和 `vault-live/`（iCloud Wissen 活库）里定位原始材料——逐字稿、访谈笔记、演讲转录、长文。优先读已有的精读笔记（如 `vault-live/raw/` 下的笔记），再按需回到原始逐字稿补细节。
2. **提取细节**：从逐字稿里取关键段落的原文。逐字稿很长时不要全读，按笔记里的时间戳定位话题段落，只提取英文原文（带时间戳的逐字稿通常是中英逐行交错，用下面的抽取法）。目标是抓到手势级的具体细节：人名、项目名、数字、原话、场景。
3. **成文**：按素材的时间/叙事顺序写成故事，标准见 [references/style.md](references/style.md)。先存到工作区，文件名 `YYYY-MM-DD - <标题>.md`。
4. **发布**：运行 `scripts/publish.sh <文章路径>`，复制到 iCloud「睡前读物」目录。
5. **索引**：若 iCloud 目录里已有 `INDEX.md`，在其上加一行（日期 + 标题 + 一句话）；没有则不建，等用户要。
6. **回复**：给文件链接，一两句说明文章结构。不主动加下一步建议（用户在收尾场景）。

## 逐字稿抽取法

带时间戳的逐字稿（如 `interview_transcript_timestamped.md`，每 30 秒一个 `## [HH:MM:SS]` 锚点，EN/中 逐行交错）：

```bash
# 取第 A 到 B 行之间的时间锚点列表，定位话题段落
grep -n '^## \[' <逐字稿文件>
# 抽取该段落的英文原文并去重叠（自动字幕逐行累积，去掉被上一行包含的行）
extract() { sed -n "${1},${2}p" <逐字稿文件> | grep '^\*\*EN\*\*' | awk '{ if (index($0, prev) != 1) print; prev=$0 }'; }
extract <起始行> <结束行>
```

笔记里没有时间戳时，先读笔记拿结构和关键事实，再用 grep 关键词在逐字稿里定位原话。

## 发布脚本

```bash
bash scripts/publish.sh "<工作区文章的绝对路径>"
```

脚本会把文章复制到 `~/Library/Mobile Documents/com~apple~CloudDocs/睡前读物/` 并输出目标路径。工作区原稿保留不动。

## 边界

- 只改写用户已有或指定的素材。素材不够时问用户要链接或文件，不擅自联网另找。
- 素材里的每个具体细节（数字、引语、项目名）必须能在逐字稿或笔记中找到出处，不补写。
- 文章用中文写，人物原话可保留简短英文短语（如 "meat proxy"）。
